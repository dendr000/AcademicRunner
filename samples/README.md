# 샘플 문제

앱을 처음 써 볼 때 쓰는 학원 과제 문제 5개의 **시작 코드**입니다(풀이는 들어 있지 않습니다). 학원의 확인을 받아 확인 용도로 넣었습니다.

- 입출력 문제: `Lv0_기초연습/01_A+B`, `02_구구단` (C, C++, Java)
- 함수 작성 문제: `Lv0_기초연습/07_1부터_n까지의_합` (C, C++, Java, JavaScript, Python)
- SQL 문제: `Lv0_기초연습/22_전체_학생_조회`, `25_학과별_학생_수` (기본 표 student 가 자동으로 들어갑니다)
- `original/` 은 시작 코드 보관용입니다. 앱의 "시작 코드로"와 풀이 진행 표시가 이것과 비교합니다.

`C:\dev\AcademicTest` 가 없는 PC 에서 `npm start` 로 앱을 켜면 이 폴더를 문제 폴더로 엽니다(파일 > 문제 폴더 선택으로 바꿀 수 있습니다). 풀이를 적으면 이 폴더의 파일이 바뀌므로 다시 받고 싶으면 `git checkout -- samples` 로 되돌립니다.
