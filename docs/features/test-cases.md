# 시험 케이스 (M5)

## 무엇인가

문제마다 "입력과 기대 출력" 짝(케이스)을 저장해 두고, 버튼 한 번으로 전부 실행해 통과/실패를 봅니다. 사이트의 숨은 테스트는 알 수 없으므로 이 시험은 1차 확인용입니다. 통과해도 사이트 정답이라는 보장은 없습니다.

## 사용 방법

1. 입력 탭에 입력을 쓰고 실행(`F5`)합니다.
2. 결과가 맞으면 "케이스로 저장"을 누릅니다. 방금의 입력과 출력이 케이스가 되어 케이스 탭에 들어갑니다(기대 출력은 고칠 수 있음).
3. 케이스 탭에서 "케이스 추가"로 직접 만들 수도 있습니다. 이름·입력·기대 출력을 쓰고 "저장".
4. "전부 실행(F7)"을 누르면 컴파일은 한 번만 하고 케이스를 차례로 실행합니다. 각 케이스에 `통과` / `실패` / `시간 초과` / `오류` 가 붙고 위쪽에 `3 / 4 통과` 가 나옵니다.
5. 실패한 케이스를 누르면 처음 달라진 줄의 기대/실제와 실제 출력 전체, 오류 출력을 보여 줍니다.

| 키 | 동작 |
|---|---|
| `F7` | 케이스 전부 실행 |
| `Ctrl+3` | 케이스 탭으로 |
| `Shift+F5` | 실행 중인 케이스 실행 중지 (남은 케이스는 `건너뜀`) |

## 비교 규칙

채점 사이트와 비슷하게 아래 차이는 무시합니다.

- 줄바꿈 CRLF / LF 차이
- 각 줄 오른쪽 공백(줄 끝 공백)
- 맨 끝의 빈 줄

줄 안의 공백 개수, 대소문자, 중간의 빈 줄은 다르면 실패입니다(출력 형식도 문제의 일부이므로).

## 저장 위치

케이스는 앱 데이터 폴더의 `cases.json` 에 저장합니다(문제 폴더는 건드리지 않음). 문제 단위로 최대 200개, 입력·기대 출력 각 100KB, 이름 80자까지입니다. 파일이 깨져도 앱은 빈 상태로 시작하고 다시 저장할 수 있습니다.

## 구성 용어 설명

| 용어 | 뜻 |
|---|---|
| 케이스 | 한 번의 시험: 프로그램에 넣을 입력 + 나와야 할 출력 |
| 기대 출력 | 이 입력에서 나와야 한다고 내가 정한 출력 |
| diff | 기대와 실제의 차이. 여기서는 처음 달라진 줄을 보여 준다. |
| 건너뜀 | 중지해서 실행하지 않은 케이스 |

## 관련 파일

- `electron/core/case-store.js` 케이스 저장(추가·수정·삭제, 크기·개수 제한)
- `electron/core/output-compare.js` 기대/실제 출력 비교
- `electron/core/run-service.js` 컴파일 1회 + 케이스별 실행(`request.cases`)
- `src/ui/cases-panel.js` 케이스 탭 화면
