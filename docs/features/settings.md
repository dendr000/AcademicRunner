# 환경 설정

> 메뉴 설정 > 환경 설정...에서 연다(단축키는 단축키 설정 창에서 직접 지정할 수 있다).

| 항목 | 범위 | 저장 위치 |
| --- | --- | --- |
| 글자 크기 | 8~40 | 화면 저장소(localStorage `academicrunner.editor`) |
| 탭 칸 수 | 2, 4, 8 | 같음 |
| 긴 줄 바꿈 | 켬/끔 | 같음 |
| 미니맵 | 켬/끔 | 같음 |
| 실행 시간 제한 | 1~120초 | 앱 설정 파일(settings.json, 메인 프로세스가 범위 검사) |

- 바꾸면 바로 편집기에 적용된다. 시간 제한은 다음 실행부터 적용된다.
- "기본값으로" 버튼은 편집기 항목(글자 크기 14, 탭 4칸, 줄 바꿈·미니맵 끔)을 되돌린다. 시간 제한은 건드리지 않는다.
- 글자 크기는 단축키(Ctrl+= / Ctrl+- / Ctrl+0)와 Ctrl + 휠로 바꿔도 저장된다.
- 저장값이 깨졌거나 범위를 벗어나면 그 항목만 기본값으로 돌아간다.
- 탭 칸 수는 파일 내용을 보고 짐작하지 않고 설정값을 쓴다.

## 실행 시간

- 한 번 실행과 케이스 실행 모두 걸린 시간을 보여 준다. 케이스를 전부 실행하면 요약에 "가장 느린 ○○ms"가 붙는다.
- 메모리 사용량은 재지 않는다. Windows 에서는 실행이 끝난 프로세스의 최대 메모리를 안정적으로 얻을 방법이 없고(주기적으로 훑으면 짧은 실행을 놓친다), 학원 과제에서는 시간이 더 쓸모 있어서 뺐다.

## 용어

- **미니맵**: 코드 전체를 축소해 오른쪽에 보여 주는 그림.
- **줄 바꿈(word wrap)**: 화면보다 긴 줄을 옆으로 스크롤하지 않고 아래 줄로 이어 보여 주는 기능. 파일 내용은 바뀌지 않는다.
