# 폰 접속 (읽기 전용)

> PC 앱이 작은 웹 서버를 열고, 같은 와이파이의 폰 브라우저로 접속해 문제와 코드를 본다. 별도 앱 설치는 없다.

## 하는 일

- 문제 목록(검색 가능), 문제마다 작성함/안 품 표시, 풀이 코드 보기, 코드 전체 복사(제출 사이트에 붙여 넣기용).
- 읽기 전용이다. 폰에서 코드를 고치거나 실행하지는 못한다(서버는 GET 요청만 받는다).
- 통과 기록은 PC 앱 화면에만 있어서 폰에는 "작성함/안 품"만 보인다.

## 사용 방법

1. PC 앱의 설정 > 환경 설정 > "폰에서 접속 허용"을 켠다.
2. 창에 나온 주소(`http://<PC 주소>:8787/#t=...`)를 복사해 폰 브라우저(Chrome, 삼성 인터넷)에서 연다. 한 번 열면 토큰이 폰에 저장되어 다음부터는 `http://<PC 주소>:8787/` 만 열면 된다.
3. 토큰을 새로 만들면(`토큰 새로 만들기`) 이전 토큰은 바로 못 쓰게 되고, 폰에서 새 주소로 다시 열어야 한다.

## 보안

- 기본은 꺼짐이다. 켜는 것은 사용자가 환경 설정에서 직접 한다.
- 접속 토큰이 필수다(48자리 무작위). 토큰은 앱 설정 파일(settings.json)에만 저장하고 코드·문서에는 없다. 주소의 `#` 뒤에 넣어 서버 기록에 남지 않게 했다.
- 사설 주소(같은 와이파이, 127.x, 10.x, 172.16~31.x, 192.168.x, Tailscale 100.64~127.x)에서 온 요청만 받고 그 밖은 403.
- 틀린 토큰을 1분에 10번 보내면 그 주소는 잠시 429 로 막는다.
- 파일 경로는 풀이 파일 읽기 모듈이 검사한다(문제 폴더 밖, `..`, 폴더 구분자는 거부).
- 공유기 포트를 열어 집 밖에서 직접 접속하는 것은 권하지 않는다. 집 밖은 Tailscale 같은 개인 VPN 을 쓴다.
- 앱 창이 열려 있는 동안만 서버가 동작한다. 서버 주소는 http 라서 와이파이 안의 다른 사람이 통신을 엿볼 수 있다. 공용 와이파이에서는 켜지 않는다.

## 문제 해결

- 폰에서 "연결하지 못했습니다": PC 앱이 켜져 있는지, 폰이 같은 와이파이인지, Windows 방화벽의 개인 네트워크 허용 창이 뜨면 허용했는지 확인한다.
- "포트를 다른 프로그램이 쓰고 있습니다": 설정 파일의 `mobilePort`(기본 8787, 1024~65535)를 다른 값으로 바꾸고 앱을 다시 켠다.
- 복사가 안 되면: http 주소라 브라우저 복사 기능이 막힐 수 있다. 코드 칸을 길게 눌러 직접 복사한다.

## 구조

- `electron/core/mobile-auth.js` 사설 주소 검사, 토큰 생성·비교, 실패 횟수 제한
- `electron/core/mobile-server.js` 읽기 전용 HTTP 서버(`/api/problems`, `/api/file`, 정적 화면)
- `electron/core/mobile-control.js` 켜기·끄기, 접속 주소 목록
- `src/mobile/` 폰 화면, `src/ui/mobile-section.js` 환경 설정 창의 폰 접속 부분

## 용어

- **토큰**: 접속할 때 내는 비밀 문자열(비밀번호 역할).
- **사설 주소**: 집·사무실 안에서만 쓰는 주소(인터넷에서는 보이지 않음).
- **Tailscale**: 집 밖에서도 내 기기끼리만 안전하게 연결해 주는 개인 VPN.
