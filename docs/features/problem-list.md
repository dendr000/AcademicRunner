# 문제 목록과 검색 (M1)

## 무엇인가

문제 풀이 폴더를 읽어 단계(Lv0~Lv7)별 문제 목록을 왼쪽에 보여 주고, 번호나 제목으로 찾거나 단계로 걸러 볼 수 있게 합니다. 문제를 고르면 선택 표시가 되고 가운데에 이름과 파일 목록이 나옵니다. 편집기는 M2 에서 추가합니다.

## 사용 방법

1. 앱을 켜면 설정된 문제 폴더(기본 `C:\dev\AcademicTest`)를 자동으로 읽습니다. 아래 상태줄에 폴더와 문제 개수가 보입니다.
2. 검색창에 `15`, `05`, `구구단`, `fizz` 처럼 쓰면 맞는 문제만 남습니다. 공백과 대소문자는 무시합니다.
3. "전체 단계" 드롭다운으로 한 단계만 볼 수 있습니다.
4. 폴더가 다른 곳에 있으면 오른쪽 위 "폴더 선택"으로 지정합니다. 고른 폴더는 다음 실행에도 기억합니다.

## 폴더 규칙 (스캐너가 읽는 방식)

```text
문제폴더/
  Lv0_기초연습/
    01_A+B/Main.java        <- 입출력 문제 (파일 이름이 Main 으로 시작)
    07_1부터n까지의합/Solution.java   <- 함수 문제 (파일 이름이 Solution 으로 시작)
  original/   docs/   .git/ ... <- 이름 규칙에 맞지 않아 무시
```

- 단계 폴더 이름은 `Lv숫자_이름`, 문제 폴더 이름은 `숫자_이름` 입니다.
- 풀이 파일의 언어는 확장자로 정합니다 (`.java` `.py` `.js` `.c` `.cpp` `.sql`).
- 앱은 목록을 만들 때 파일을 읽기만 하고 바꾸지 않습니다.

## 용어 설명

| 용어 | 뜻 |
|---|---|
| 스캐너 | 문제 폴더를 훑어 단계·문제·파일 목록을 만드는 코드(`electron/core/scanner.js`) |
| 입출력 문제 | 키보드 입력을 받아 화면에 출력하는 문제 (`Main`) |
| 함수 문제 | 정해진 이름의 함수 하나만 완성하는 문제 (`Solution`) |
| 설정 저장소 | 문제 폴더 경로를 앱 데이터 폴더의 JSON 파일에 저장하는 코드(`electron/core/settings.js`) |

## 오류 처리

- 폴더가 없으면 목록 자리에 안내 문구가 나옵니다. "폴더 선택"으로 다시 지정하면 됩니다.
- 선택한 경로가 폴더가 아니면 별도 안내가 나옵니다.
- 폴더를 바꾸면 이전 선택은 지워집니다.
