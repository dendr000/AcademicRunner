# 메뉴바와 단축키 설정 (M8)

## 무엇인가

- 창 맨 위(Windows 기본 제목 줄 바로 아래)에 **파일 · 보기 · 이동 · 실행 · 설정** 메뉴가 있습니다. 항목 오른쪽에는 지금 지정된 단축키가 보입니다.
- **설정 > 단축키 설정**(기본 `Ctrl+,`)에서 모든 동작의 키를 직접 눌러 바꿀 수 있습니다.

## 메뉴 구성

| 메뉴 | 항목 |
|---|---|
| 파일 | 문제 폴더 선택, 지금 저장, 코드 전체 복사, 시작 코드로 되돌리기, 종료 |
| 보기 | 문제 목록 접기/펴기, 테마 전환, 편집기 글자 크게/작게/기본 |
| 이동 | 빠른 이동, 이전 문제, 다음 문제 |
| 실행 | 실행, 중지, 컴파일 확인, 케이스 전부 실행, 하단 입력/출력/케이스 탭 |
| 설정 | 단축키 설정 |

마우스로 누르거나, 열린 메뉴에서 `↑` `↓`(항목) `←` `→`(메뉴 이동) `Esc`(닫기)를 쓸 수 있습니다. 메뉴를 하나 연 뒤에는 다른 메뉴 위로 마우스만 옮겨도 바뀝니다.

## 단축키 바꾸는 법

1. `설정 > 단축키 설정...` 을 엽니다.
2. 바꿀 동작의 키 칸을 누르면 "키를 누르세요" 로 바뀝니다.
3. 새 키를 누릅니다. `Esc` 는 취소, `Backspace`/`Delete` 는 키 지우기(그 동작은 키 없이 메뉴로만 실행).
4. 바꾼 칸은 테두리가 파란색이고, 오른쪽 `기본값` 버튼으로 그 항목만, 아래 `전체 초기화` 로 전부 되돌립니다.

바꾼 값은 즉시 적용되고(메뉴의 키 표시, 버튼 옆 `(F5)` 안내, 툴팁 포함) 다음 실행에도 유지됩니다.

### 받지 않는 키

- 글자·숫자만 누르는 키(`A`, `Shift+A`, `Enter` 등): 코드 입력과 겹치므로 `Ctrl` 또는 `Alt` 와 함께 누르거나 `F1`~`F12` 를 써야 합니다.
- 편집 기본 키: `Ctrl+C` `Ctrl+V` `Ctrl+X` `Ctrl+Z` `Ctrl+Y` `Ctrl+A` `Ctrl+F` `Ctrl+H` `Ctrl+D`, `Alt+F4`, `Esc`.
- 이미 다른 동작이 쓰는 키: 이유(어느 동작이 쓰는지)를 보여 주고 받지 않습니다. 먼저 그 동작의 키를 바꾸거나 지우세요.

## 고정된 키 (설정 목록에 없음)

- 편집기 안: `Alt+↑/↓` 줄 이동, `Shift+Alt+↑/↓` 줄 복사, `Ctrl+Shift+K` 줄 삭제, `Ctrl+/` 주석, `Ctrl+Space` 자동 완성 (편집기 기본)
- 실행 중 입력 줄: `Enter` 보내기, `Ctrl+D` 입력 끝

## 저장 위치

앱 화면 저장소(localStorage)의 `academicrunner.keymap` 에 **기본값과 다른 것만** 저장합니다. 값이 손상됐거나 같은 키가 겹치면 그 부분만 버리고 기본 키로 동작합니다. 문제 폴더에는 아무것도 쓰지 않습니다.

## 용어 설명

| 용어 | 뜻 |
|---|---|
| 동작(action) | "실행", "지금 저장" 처럼 이름 붙은 기능. 키와 메뉴는 같은 동작을 부릅니다 |
| 키 묶음(chord) | `Ctrl+Shift+↑` 처럼 한 번에 누르는 키 조합 |
| localStorage | 앱 화면이 자기 설정을 저장하는 작은 저장 공간 |

## 관련 파일

- `src/ui/keymap.js` 동작 목록·기본 키·키 이벤트 변환·충돌 검사·저장 (화면 없는 순수 로직)
- `src/ui/shortcuts.js` 동작 등록소(`registerActions`/`runAction`)와 키 처리(캡처 단계)
- `src/ui/menubar.js` 메뉴바, `src/ui/keymap-dialog.js` 단축키 설정 창, `src/styles/menubar.css`
- 동작을 등록하는 곳: `src/renderer.js`(앱 전체), `src/ui/run-panel.js`(실행 관련)
