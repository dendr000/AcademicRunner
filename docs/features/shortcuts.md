# 단축키와 편의 기능 (M7)

## 단축키 전체

| 키 | 동작 |
|---|---|
| `Ctrl+S` | 지금 저장 (자동 저장은 마지막 입력 후 약 0.8초) |
| `F5` / `Ctrl+Enter` | 실행. 함수 문제는 케이스 전부 실행 |
| `Shift+F5` | 실행 중지 |
| `F6` | 컴파일(문법) 확인 |
| `F7` | 케이스 전부 실행 |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | 하단 입력 / 출력 / 케이스 탭 |
| `Ctrl+P` | 빠른 이동: 검색칸으로 가서 번호나 제목을 쓰고 `Enter` 를 누르면 맨 위 문제를 엽니다 |
| `Alt+↑` / `Alt+↓` | 목록에서 이전 / 다음 문제 (검색·단계 필터를 건 상태면 보이는 문제끼리) |
| `Ctrl+B` | 왼쪽 목록 접기·펴기 (상태를 기억) |
| `Ctrl+Shift+C` | 코드 전체 복사 (사이트에 붙여 넣기용) |
| `Ctrl+Shift+R` | 시작 코드로 되돌리기 (확인창이 뜸) |
| `Ctrl+휠` | 편집기 글자 크기 |

## 기억하는 것

- 마지막에 연 문제: 앱을 다시 켜면 그 문제를 바로 엽니다. 문제 폴더에서 사라졌으면 열지 않습니다.
- 왼쪽 목록을 접었는지 여부, 문제별 마지막 입력, 라이트/다크 선택.
- 이 값들은 앱 화면의 저장소(localStorage)에 두며, 문제 폴더에는 아무것도 쓰지 않습니다.

## 하단 상태줄

왼쪽에 문제 폴더와 문제 수, 오른쪽에 찾은 도구의 버전(Java, Python, Node)과 앱 버전이 보입니다. 도구를 못 찾으면 `없음` 이라고 나옵니다.

## 용어 설명

| 용어 | 뜻 |
|---|---|
| 빠른 이동 | 마우스 없이 검색으로 문제를 여는 기능 |
| localStorage | 앱 화면이 자기 설정을 저장하는 작은 저장 공간 |
| 캡처 단계 | 편집기보다 먼저 키 입력을 받는 방식(편집기가 단축키를 가로채지 못하게 함) |

## 관련 파일

- `src/ui/shortcuts.js` 앱 전체 단축키 등록
- `src/ui/problem-nav.js` 이전/다음 문제 계산(순수 함수)
- `src/ui/run-panel.js` 실행 관련 키(F5, F6, F7, Ctrl+1/2/3)
- `src/renderer.js` 연결, 마지막 문제·목록 접기 기억, 도구 버전 표시
