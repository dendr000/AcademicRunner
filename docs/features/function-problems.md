# 함수 작성 문제 시험 (M6)

## 무엇인가

`Solution` 파일(`solution(...)` 함수만 고쳐 제출하는 문제)은 `main` 이 없어 그대로는 실행할 수 없습니다. 이 기능은 **인수와 기대 반환값을 케이스로 저장**해 두면, 앱이 임시 폴더에서 풀이를 호출하는 코드를 붙여 실행하고 반환값을 비교해 줍니다. 풀이 파일은 한 글자도 바뀌지 않습니다. 사이트의 숨은 테스트는 알 수 없으므로 1차 확인용입니다.

## 사용 방법

1. 함수 문제(목록에 `함수` 표시)를 엽니다. 실행(`F5`)을 누르면 입력 탭 대신 **케이스 탭**이 열리고 케이스를 전부 실행합니다.
2. "케이스 추가"를 누르고 입력칸에 **인수를 JSON 배열**로, 기대 출력칸에 **기대 반환값을 JSON** 으로 씁니다.

| 문제 | 인수(입력칸) | 기대 반환값 |
|---|---|---|
| `solution(10)` 이 `55` | `[10]` | `55` |
| `solution("abc")` 이 `"cba"` | `["abc"]` | `"cba"` |
| `solution([1,2,3], 2)` 이 `[2,4,6]` | `[[1,2,3], 2]` | `[2,4,6]` |
| 참/거짓을 돌려줄 때 | `[4]` | `true` |

3. `F7` 또는 "전부 실행"을 누르면 케이스마다 `통과` / `실패` / `오류` 가 붙습니다. 실패하면 기대와 실제 반환값을 나란히 보여 줍니다.
4. 컴파일만 확인하려면 `F6` (케이스 없이도 됩니다).

## 비교 규칙

반환값은 JSON 값으로 비교합니다. 공백·키 순서가 달라도 같고, `1` 과 `1.0` 도 같습니다. 소수는 상대 오차 1e-9 이내면 같은 값으로 봅니다. 풀이가 `System.out.println`, `print`, `console.log` 로 디버그 출력을 해도 괜찮습니다(반환값은 마지막 줄로 읽습니다).

## 언어별 동작

| 언어 | 방식 | 지원하는 타입 |
|---|---|---|
| Java | `solution` 의 반환형·매개변수 타입을 읽어 호출 코드(`__ArHarness`)를 생성, 컴파일 1회 + 케이스마다 실행 | `int` `long` `short` `byte` `double` `float` `boolean` `char` `String`, 그 배열(2차원 포함), `List<...>` (`Integer` `Long` `Double` `Boolean` `String` `Character`). 반환값은 배열·`List`·`Map` 도 가능 |
| Python | 풀이 뒤에 호출 코드를 붙여 실행(인수는 표준 입력의 JSON) | JSON 으로 표현되는 값 전부 |
| JavaScript | 위와 같음 | JSON 으로 표현되는 값 전부 |

Java 에서 지원하지 않는 타입(`Map` 매개변수, 사용자 클래스 등)이나 인수의 타입 불일치(`int` 자리에 `"x"`)는 해당 케이스만 `오류` 와 이유를 보여 줍니다. `void` 를 돌려주는 `solution` 은 비교할 값이 없어 실행하지 않습니다.

## 용어 설명

| 용어 | 뜻 |
|---|---|
| 하니스(harness) | 풀이를 대신 호출해 주는 시험용 코드. 임시 폴더에만 만들고 실행 뒤 지웁니다. |
| JSON | `[1,2]`, `"abc"`, `true` 처럼 값을 글자로 적는 형식 |
| 반환값 | `solution` 이 `return` 으로 돌려주는 값 |

## 관련 파일

- `electron/core/harness/java-harness.js` Java 호출 코드 생성(시그니처 읽기, 값 변환)
- `electron/core/json-compare.js` 반환값 비교, 마지막 줄 고르기
- `electron/core/runners/{java,python,javascript}.js` 함수 문제용 단계 구성
- `electron/core/run-service.js` 함수 문제 분류(`kind`), 케이스별 인수 전달
- `src/ui/cases-panel.js`, `src/ui/run-panel.js` 안내 문구, F5 → 케이스 실행

## 시험

`test/json-compare.test.js`, `test/java-harness.test.js`, `test/run-service-function.test.js`(JS·Python·Java 실제 실행: 통과/실패/예외/잘못된 인수/`void`/`solution` 없음/컴파일 확인). 화면은 개발 실행에서 실제 마우스·키 입력으로 확인했습니다(F5 → 케이스 탭, 케이스 추가, 전부 실행, 실패 상세, 라이트/다크).

## 아직 하지 않은 것

사이트 문제 화면의 예시(`solution(10) → 55`)를 읽어 케이스로 만드는 스파이크는 사이트 접근 없이 확인할 수 없어 보류했습니다. 필요하면 예시를 직접 케이스로 입력하세요.
